# Входящие документы

Сюда складываются сметы и другие документы (.docx, .xlsx, .pdf) для обработки.

Как добавить файл через сайт GitHub:

1. Откройте эту папку `inbox` в репозитории на github.com.
2. Нажмите **Add file → Upload files**.
3. Перетащите файлы и нажмите **Commit changes**.

Результаты обработки складываются в папку `outbox`.
