# Веб-приложение «Анализ смет»

Сотрудник открывает страницу в браузере, загружает смету (.docx/.xlsx),
нажимает кнопку — скачивает Excel-книгу проекта с 10 листами.

Никакой установки на компьютер сотрудника. Работает в любом браузере.

---

## Что нужно для запуска

1. Сервер (Windows Server, Linux, VPS) или даже обычный компьютер в сети
2. Python 3.10+
3. API-ключ Anthropic (получить на console.anthropic.com)

---

## Быстрый запуск (локально)

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Задать API-ключ (один раз)
# Windows:
set ANTHROPIC_API_KEY=sk-ant-...ваш-ключ...

# Linux/Mac:
export ANTHROPIC_API_KEY=sk-ant-...ваш-ключ...

# 3. Запустить
python app.py
```

Открыть в браузере: http://localhost:5000

---

## Запуск через Docker (рекомендуется для сервера)

```bash
# Собрать образ
docker build -t smeta-web .

# Запустить
docker run -d \
  -p 5000:5000 \
  -e ANTHROPIC_API_KEY=sk-ant-...ваш-ключ... \
  --name smeta-web \
  --restart unless-stopped \
  smeta-web
```

Приложение доступно на http://ваш-сервер:5000

---

## Открыть доступ сотрудникам

### Вариант А — через локальную сеть (простейший)
Если сервер в одной сети с сотрудниками:
- Узнайте IP сервера (команда `ipconfig` на Windows или `hostname -I` на Linux)
- Сотрудники открывают: http://192.168.1.X:5000

### Вариант Б — через домен (для удалённой работы)
1. Арендуйте VPS (Timeweb, Selectel, Yandex Cloud — от 500 руб/мес)
2. Установите Docker, разверните образ
3. Настройте nginx как прокси и SSL-сертификат (Let's Encrypt)
4. Сотрудники открывают: https://сметы.ваша-компания.ru

### Вариант В — Railway.app (самый простой для prod)
1. Зайдите на railway.app
2. Создайте новый проект → Deploy from GitHub
3. Загрузите код на GitHub (или используйте Railway CLI)
4. Добавьте переменную окружения ANTHROPIC_API_KEY в настройках
5. Railway даст URL вида: https://smeta-web.up.railway.app

---

## Как использовать

1. Открыть страницу в браузере
2. Перетащить файл сметы (.docx или .xlsx) или нажать для выбора
3. Нажать «Создать книгу проекта»
4. Подождать 30-60 секунд
5. Файл Excel скачается автоматически

## Структура Excel-книги (10 листов)

| Лист | Содержание |
|------|-----------|
| 📊 Сводный бюджет | НМЦ, структура затрат, смета vs рынок, КПЭ |
| 🗂️ Оглавление | Навигация по книге |
| 📋 Дефектная ведомость | Все работы с объёмами и стоимостью |
| 📋 Сводка по разделам | Итоги по разделам + НМЦ |
| 👷 ФОТ (оплата труда) | ОТ рабочих: ОТ на ед.изм. и ОТ итого |
| 🧱 Ведомость материалов | Все материалы с ценами |
| 💰 Сравнение цен матер. | Сметные vs рыночные цены (÷ 1.22 НДС) |
| 💰 Сводка цен матер. | Экономия на закупке по разделам |
| ⚒️ Стоимость работ | Сметная ОТ vs расценки бригад |
| ⚒️ Итоговое сравнение | ОТ↔Рынок + НР/СП + расшифровка экономии |

---

## Ключевая логика сравнения

- **Материалы** ↔ **Рыночные цены** (petrovich.ru / lemanapro.ru ÷ 1.22)
- **ОТ рабочих** ↔ **Расценки бригад** (otdelka-spb.ru / demontazh-centr.ru)
- **Накладные расходы** = 0 при самостоятельной организации (не платите подрядчику)
- **Сметная прибыль** = 0 при самостоятельной организации (нет посредника)
