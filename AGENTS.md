# Инструкции для агента по обработке лотов

## Структура папок

- `inbox/` — входящие лоты, каждый лот в своей подпапке (`inbox/Лот 01 - .../`).
- `inbox/архив/` — уже обработанные лоты.
- `common/` — общие файлы для всех лотов: промт, тарификатор, прайсы, шаблоны.
- `outbox/` — результаты, в подпапке с тем же именем, что и лот.

## Порядок работы

1. Перед обработкой прочитать все файлы в `common/` и следовать им.
   Если в `common/` есть файл с промтом/методикой, он важнее общих правил ниже.
2. Обработать каждый лот из `inbox/` (кроме `архив/`).
3. Результаты положить в `outbox/<имя лота>/`, при нескольких лотах — также
   `outbox/Сводная по лотам.xlsx`.
4. Обработанные лоты перенести в `inbox/архив/`.

## Общие правила

- Отвечать пользователю на русском языке.
- Не придумывать цены и объёмы: если данных нет, явно пометить это в результате.
