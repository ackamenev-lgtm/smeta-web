# Инструкции для агента по обработке лотов

## Структура папок

- `inbox/` — входящие лоты, каждый лот в своей подпапке (`inbox/Лот 01 - .../`).
- `inbox/архив/` — уже обработанные лоты.
- `common/` — общие файлы для всех лотов: промты, тарификатор, справочники, бланк.
- `outbox/` — результаты, в подпапке с тем же именем, что и лот.
- `outbox/Реестр тендеров НЕОСТРОЙ.xlsx` — рабочий реестр тендеров (ведётся здесь).

## Какой промт применять

- **Коммерческие тендеры** (СМР, ремонт, fit-out, КТО) — основной промт
  `common/Промт и тарификатор/_ПРОМТ — расчёт тендера и КП НЕОСТРОЙ.md`.
- **Сметы 44-ФЗ / 223-ФЗ** — структура «Книги проекта» (10 листов) по
  `common/ПРОМТ_CLAUDE_CODE.md`, но этот промт старый, поэтому:
  - рыночные расценки на работы берутся **только из тарификатора v2**, как и для
    коммерческих тендеров (цена КП — H/I, оплата бригаде — L/M, нормы — лист
    «Нормы и нормо-часы»); сайты otdelka-spb / demontazh-centr и встроенная
    таблица «Примерные расценки» не используются;
  - работы, которых нет в тарификаторе, — по правилу основного промта (рынок 2–3
    подрядчиков, бригада = норма × ставка часа) и в список «Добавить в тарификатор»;
  - цены материалов — по шагу 4 основного промта (минимум 2 источника, ÷ 1,22);
    встроенная таблица цен материалов старого промта — только крайний случай с
    пометкой «оценка»;
  - если по лоту нужно участие (КП, себестоимость, наценка) — дополнительно шаги
    5–11 основного промта с типом тендера «Госзакупки 44-ФЗ / 223-ФЗ».
- Метод сборки тарификатора лежит в `common/архив/_tarif_v2_data/`. При расчёте
  лотов эту папку не читать и не искать по ней.

## Как считать, не тратя контекст

Справочники xlsx целиком не читать и не копировать в чат. Цифры брать командами
из `tools/` (схема входов — `tools/README.md`):

- `python tools/tarif.py search|art|kit|cat|rash|rate|types|params` — артикулы,
  цены КП, оплата бригаде, нормы, комплекты, отходы, наценки, ставки часа;
- `python tools/prices.py search` — база цен материалов. Запись свежая (до 45 дней)
  берётся как есть, в интернет за ней не ходить;
- два источника в интернете — только по позициям, которые `python tools/prices.py top`
  пометил «два источника» (они дают ~80 % суммы материалов), плюс всё оборудование
  и позиции дороже 5 % суммы. Остальное — база, один источник или аналог с пометкой
  «оценка»;
- найденные цены писать в `outbox/<лот>/Цены.json`. Файл базы в `common/` лот не меняет;
- расчёт собирать в `outbox/<лот>/Расчёт.json` и запускать `python tools/budget.py`:
  он делает бюджет, КП, карту, письмо и строку реестра. Код книги с нуля не писать;
- PNG смотреть только у листов «Свод», «Работы», «Материалы»:
  `python tools/render.py <бюджет.xlsx> --sheets "Свод,Работы,Материалы" --out <папка>/png`.
  Нет LibreOffice — один раз `bash tools/bootstrap.sh`, не ставить пакеты заново в каждом чате;
- поиск цен в интернете отдавать подагенту с моделью `composer-2.5-fast`. В его промпт —
  только список позиций (название, ед., категория), без справочников и без переписки.
  Подагент возвращает JSON для `Цены.json`;
- большой пересчёт готового лота начинать новым чатом по файлам в `outbox/`, а не
  продолжать длинную переписку.

## Подбор тендеров в Тендерплане

Рабочее правило — `common/Тендерная воронка/Критерий отбора.md`.
Черновик с примерами сделок — `common/Тендерная воронка/criteria.md`.

Агент смотрит закупки, которые уже нашли ключи Тендерплана, и подходящие
помечает только меткой «Кандидат ИИ» плюс короткий комментарий. Метку
«Первичный отбор» ставит пользователь после проверки. В Битрикс, воронку
«Тендеры», стадию «Первичный отбор», попадают только тендеры с меткой
«Первичный отбор». Сделки Битрикса агент не создаёт и не двигает. Ключи,
фильтры и остальные метки не меняет.

## Пути из промтов

Промты писались для Windows. Соответствие:

| В промте | В репозитории |
|---|---|
| `Сметы\Промт и тарификатор\...` | `common/Промт и тарификатор/...` |
| `Desktop\Титульник.docx` | `common/Титульник.docx` |
| `Desktop\Маркетинг До\Реквизиты - НЕОСТРОЙ ООО.docx` | `common/Реквизиты - НЕОСТРОЙ ООО.docx` |
| `Реестр тендеров НЕОСТРОЙ.xlsx` | `outbox/Реестр тендеров НЕОСТРОЙ.xlsx` (реестр в `common/` не трогать) |
| папка тендера, копии `_НЕОСТРОЙ` | `outbox/<имя лота>/` (оригиналы в `inbox/` не менять) |

Для форм «Сведения об опыте», анкет участника и требований к опыту:
`common/Референс-лист 2020-2025 (НеоСтрой).docx` (готовый документ для приложения
к заявке) и `common/Выполненные работы 2020-2025 НЕО.xlsx` (данные по годам — для
подбора аналогичных договоров по виду работ и сумме). Подбирать договоры, близкие
к предмету лота; номера и даты договоров, акты, отзывы, которых нет в файлах, —
перечислить в отчёте как «подставить».

Excel COM недоступен: пересчёт формул, проверка ошибок и рендер листов в PNG —
через LibreOffice. Если заполнялась форма `.xlsm` или защищённая форма — в отчёте
указать, что её нужно открыть и пересохранить в Excel перед подачей.

## Два вида чатов

Лоты считаются параллельно, каждый в своём чате. Общие файлы (реестр, сводная)
меняет только командный чат — иначе Pull Request'ы разных чатов конфликтуют
(xlsx не сливается автоматически).

### Чат лота («Посчитай тендер по промту, лот `inbox/<имя лота>`»)

1. Прочитать промт (см. выше). Справочники не открывать — цифры брать командами
   `tools/tarif.py` и `tools/prices.py` (раздел «Как считать, не тратя контекст»).
2. Работать только с папкой своего лота: читать `inbox/<имя лота>/`, писать
   только в `outbox/<имя лота>/`. Чужие лоты, `common/`, реестр, сводную и
   `AGENTS.md` не менять.
3. Строку реестра сохранить в `outbox/<имя лота>/Строка реестра.json` — объект с
   ключами-заголовками колонок A–T и AC–AE листа «Реестр» (без № и без формульных
   колонок N, O, P, Z), числа — числами, дата — `ГГГГ-ММ-ДД`. При пересчёте или
   переторжке — перезаписать файл (переторжку дописать в «Переторжки (история)»).
4. Лот в `inbox/архив/` не переносить: пользователь может догружать документы.
5. При догрузке документов — перечитать папку лота и пересчитать, в отчёте
   указать, что изменилось.

### Командный чат

- **«Собери реестр»** — для каждого `outbox/*/Строка реестра.json` добавить или
  обновить строку в `outbox/Реестр тендеров НЕОСТРОЙ.xlsx` (лист «Реестр», с 5-й
  строки; строку лота искать по колонке «Папка»; жёлтые колонки U–AB не трогать).
  Формулы для строки `n`:
  N `=IF(AND(ISNUMBER(Kn),ISNUMBER(Ln),Kn>0),Ln/Kn-1,"")`,
  O `=IF(AND(ISNUMBER(Kn),ISNUMBER(Ln),Ln>0),1-Kn/Ln,"")`,
  P `=IF(AND(ISNUMBER(Jn),ISNUMBER(Ln),Jn>0),Ln/Jn-1,"")`,
  Z `=IF(AND(ISNUMBER(Vn),ISNUMBER(Yn),Yn>0),Vn/Yn-1,"")`.
- **«Сделай сводную по лотам»** — `outbox/Сводная по лотам.xlsx` по всем
  рассчитанным лотам (с/с, КП, наценка, маржа, к НМЦК, решение).
- **«Обнови базу цен»** — `python tools/prices.py merge`: забрать `outbox/*/Цены.json`
  в `common/База цен материалов.csv` (свежая цена заменяет старую по той же позиции
  и магазину).
- **«Закрой лот <имя>»** — перенести `inbox/<имя лота>/` в `inbox/архив/`.
- Изменения справочников, промтов и `AGENTS.md` — тоже только здесь.

Если чат один и лот один (без параллельной работы), можно сделать всё сразу:
расчёт, строка в реестре, перенос в архив.

## Общие правила

- Отвечать пользователю на русском языке.
- Не придумывать цены и объёмы: если данных нет, явно пометить это в результате.
