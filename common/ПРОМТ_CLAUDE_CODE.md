## ⚠️ ПРАВИЛА ЕДИНИЦ ИЗМЕРЕНИЯ — ОБЯЗАТЕЛЬНО!

Смета использует нормативные единицы. В книге проекта нужны НАТУРАЛЬНЫЕ.

| Смета показывает | Единица в книге | Объём в книге     | Пример                        |
|-----------------|-----------------|-------------------|-------------------------------|
| `100 м²`, qty=0.26 | `м²`         | qty × 100 = **26**  | Стяжка 100м², 0.26 → м², 26  |
| `100 м`, qty=0.107 | `м`          | qty × 100 = **10.7**| Плинтус 100м, 0.107 → м, 10.7|
| `100 шт`, qty=0.04 | `шт`         | qty × 100 = **4**   | Умывальники                   |
| `100 соед`, qty=0.22| `соед`       | qty × 100 = **22**  | Сборка узлов                  |
| `10 компл`, qty=0.4 | `компл`      | qty × 10  = **4**   | Установка умывальников        |
| `10 шт`, qty=0.4   | `шт`          | qty × 10  = **4**   |                               |
| `т`, `м³`, `м`, `м²`, `шт`, `компл` (без множителя) | без изменений | без изменений | Обычные единицы |

**Проверка:** После перевода объёмы должны быть логичными числами (не 0.11, не 0.007).
Если видишь объём меньше 1 — скорее всего единица нормативная, надо умножить.

**ОТ на единицу** = ot_total / qty_новый (уже после перевода единиц)

## ⚠️ ПРАВИЛА ОКРУГЛЕНИЯ — ОБЯЗАТЕЛЬНО!

```python
import math

def fmt_qty(v):
    """Объём: до 3 знаков после запятой, убираем лишние нули."""
    return round(float(v or 0), 3)

def fmt_sum(v):
    """Суммы в рублях: целое число."""
    return int(round(float(v or 0)))

def fmt_pct(v):
    """Проценты: одно знак после запятой, СТРОКА типа '22.6%'."""
    return f"{round(float(v or 0), 1)}%"

def fmt_price(v):
    """Цены за единицу: два знака после запятой."""
    return round(float(v or 0), 2)
```

**Запрещено в Excel:**
- `0.08799999999999999` → должно быть `8.8` (после перевода единиц)
- `558.0700000000001` → должно быть `558.07`
- `0.2262262609179534` в ячейке % → должно быть `22.6%`
- `9.797610000000001` → должно быть `9.80`

## ⚠️ ПРАВИЛА ПО ОТ В ФОТ — ОБЯЗАТЕЛЬНО!

В листе ФОТ есть три типа строк:

1. **Работа (ГЭСН)** — ОТ > 0, вычисляется как `ot_total / qty`
2. **Поставка материала (ТЦ, артикул)** — ОТ = 0 по определению, это нормально. В ячейке ставь 0, добавь примечание «поставка»
3. **Корректирующая позиция** (например, «−5 мм», «исключать») — ОТ может быть **отрицательным**. Показывай реальное отрицательное значение, не обнуляй!

Признак поставки: шифр начинается с `[`, `ТЦ`, или нет ГЭСН-кода, и наименование содержит «поставка», артикул, размер.

3. **Итоговый бюджет**: б/НДС + с НДС (22% на материалы)
4. **Расшифровка экономии**:
   - (+) Экономия на материалах
   - (+) Отказ от НР
   - (+) Отказ от СП
   - (−) Доп.расход (рынок > норм.ОТ)
