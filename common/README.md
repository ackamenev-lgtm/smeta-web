# Общее

Две папки. Других файлов здесь нет.

## Промт и тарификатор

Промт расчёта, тарификатор, материалы и наценки, расценки бригад, база цен, бланк, реквизиты, референс-лист и выполненные работы.

`Реестр тендеров НЕОСТРОЙ.xlsx` в этой папке — заполненная история. Его не менять. Новые строки пишет командный чат в `outbox/Реестр тендеров НЕОСТРОЙ.xlsx`.

## Тендерная воронка

Правило отбора — `Критерий отбора.md`. Черновик с примерами сделок — `criteria.md`. Доступ к Тендерплану и Битриксу — `settings.local.json`.
