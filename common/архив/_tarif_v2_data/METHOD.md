# Методика оценки расценок НЕОСТРОЙ (октябрь 2026)

Компания: ООО «НЕОСТРОЙ», подрядчик СМР, ремонтов и комплексного ТО коммерческой недвижимости (гипермаркеты, РЦ/склады, ТЦ, офисы) в Санкт-Петербурге и Москве. Работы чаще всего идут на действующем объекте (стеснённость).
Все цены — ТОЛЬКО РАБОТА, без материалов и оборудования (кроме мелкого расходника: стяжки, хомуты, электроды, газ, диски), в рублях БЕЗ НДС, уровень октября 2026.

## Что нужно проставить по КАЖДОЙ позиции входного файла (ни одной не пропускать, не группировать)

| поле | смысл |
|---|---|
| `art` | артикул как во входе (для новых — см. ниже) |
| `new` | false для существующих, true для добавленных |
| `sec` | подраздел (как во входе; для новых — подраздел, куда добавлено) |
| `name`, `unit` | как во входе (для новых — своё наименование и ед.) |
| `spec` | код специальности исполнителя из списка ниже |
| `norm_h` | НОРМА ВРЕМЕНИ, чел.-ч на 1 единицу `unit` (суммарно на звено/бригаду, т.е. трудоёмкость, а не продолжительность) |
| `norm_src` | основание нормы: «ЕНиР Е__-__-__», «ВНиР В__-__», «ГЭСН(р/м) __-__-___ ×0,85», «НВ ТО (отраслевые нормы времени на ТО/ремонт)», «паспорт/регламент производителя», «экспертно (аналог __)» |
| `mkt_spb`, `mkt_msk` | РЫНОЧНАЯ цена за единицу у подрядной организации для юрлица (то, что заказчик платит подрядчику за работу), руб без НДС |
| `brig_spb`, `brig_msk` | сколько НЕОСТРОЙ может заплатить бригаде на ИП / самозанятом за единицу (сдельно), ВКЛЮЧАЯ их налог 6 % — т.е. полная сумма выплаты бригаде |
| `price_src` | «прайс» (цена найдена в открытых источниках — укажи где кратко), «аналог __» (выведена от найденной позиции), «расчёт» (норма × ставка, только если ничего не нашлось) |
| `note` | важное: подозрение на ошибку ед. изм. во входе, некорректное наименование, дубль, что не входит и т.п. Пусто, если нечего сказать |

## Нормы времени (norm_h) — на что ориентироваться

Не использовать ГЭСН из старого тарификатора как основной источник. Приоритет:
1. **ЕНиР** (Единые нормы и расценки, сборники Е1–Е40: Е2 земляные, Е3 каменные, Е4 монолит/сборный ж/б, Е5 МК, Е7 кровли, Е8 отделочные, Е9 сантехника/вентиляция, Е11 изоляция, Е19 полы, Е20 ремонт зданий, Е22 сварка, Е23 электромонтаж, Е27 автодороги, Е31 демонтаж/ремонт) — это нормы на сдельную оплату, ближе всего к реальной выработке.
2. **ВНиР / ТНиР** (ведомственные и типовые нормы) — где ЕНиР нет (ремонтные, монтаж инженерного оборудования).
3. **ГЭСН/ГЭСНр/ГЭСНм-2020 × 0,85** — сметные нормы включают перерывы и вспомогательное время, практическая выработка выше.
4. Нормы времени на ТО и ремонт оборудования (регламенты производителей, отраслевые нормы времени на ТО систем вентиляции, ПС, ворот и т.п.).
5. Экспертно по аналогу — с пометкой.
Норма должна соответствовать ед. изм. позиции (м2 ≠ м3, шт ≠ 100 шт). Работа «под ключ» = сумма операций. Если ед. изм. «нормо-час/н/ч» — norm_h = 1.

## Рынок и бригады — источники

Ищи в открытых источниках (WebSearch, при необходимости WebFetch): прайсы строительных/ремонтных/сервисных компаний СПб и Москвы для юрлиц (сайты подрядчиков, ТО-компаний, тендерные расценки), агрегаторы (profi.ru, youdo, avito-услуги — как ориентир для бригад/частников), форумы прорабов, прайсы бригад «за работу».
- Делай 8–20 поисков на группу: по ключевым подразделам и по самым дорогим/массовым позициям. Остальное — по аналогии с найденным (масштабируй по сложности/норме), помечая `аналог`.
- Рынок для юрлица обычно в 1,3–1,8 раза выше цены бригады/частника. Бригада ИП/СЗ обычно 55–75 % рыночной цены подрядчика. Это ориентир для проверки, а не правило — ставь то, что дают источники.
- Москва обычно дороже СПб на 10–25 %. Москва дешевле СПб — только если есть явное основание (укажи в note).
- Старые поля `old_mkt_spb/old_mkt_msk` из входа — НЕПРОВЕРЕННЫЕ, частично в неверных единицах. Можно учитывать как подсказку, но перепроверять.
- `our_brigade_cost` и `our_price` — текущий тарификатор компании, для справки (не копируй, оцени независимо). Если наша цена расходится с рынком > 2 раз — объясни в note вероятную причину.

## Коды специальностей (spec)

RAZ разнорабочий/демонтажник · ZEM землекоп/рабочий земляных работ · BET бетонщик/арматурщик · KAM каменщик · SVA сварщик/монтажник МК · KRO кровельщик · FAS фасадчик/промальпинист · OTD отделочник (штукатур, маляр, ГКЛ, потолки) · PLI плиточник/укладчик полов · SAN сантехник (ВиК, отопление) · VEN монтажник вентиляции · HOL холодильщик/монтажник кондиционеров · ELM электромонтажник · ETL инженер электролаборатории/ПНР · DVR монтажник дверей, окон, перегородок · VOR сервисный инженер ворот, рольставней, автоматики дверей · PSM механик ПС/подъёмников/прессов/доков · NAR монтажник наружных сетей · BLG дорожный рабочий/благоустройство · DER дезинфектор (ОЗДС) · TEX аренда техники/механизмов (norm_h = 0, цены за единицу аренды)

## Добавить недостающие работы

После всех существующих позиций добавь в каждой подгруппе своей группы работы, которых нет, но которые регулярно нужны такому подрядчику (ремонт и ТО коммерческих объектов, fit-out, СМР на складах/РЦ/магазинах). Ориентир — 15–40 новых позиций на группу, только реально востребованные и без дублей с существующими. Артикул новых: `<подраздел>.N1`, `.N2`… (например `9.1.N1`). Для новых — все те же поля.

## Формат вывода

Один JSON-файл: массив объектов с полями выше, числа — числами (не строками), округление цен до целых рублей (для дешёвых < 100 руб — до 0,5), norm_h — до 3 знаков. Сначала все существующие позиции в порядке входа, затем новые.
Перед завершением проверь скриптом Python (`python -I`): JSON читается, все `art` входа присутствуют ровно один раз, нет пустых/нулевых mkt/brig (кроме обоснованных), brig ≤ mkt почти везде, norm_h > 0 (кроме TEX).
Итоговый ответ агента — коротко (до 15 строк): сколько позиций, сколько новых, сколько цен «прайс»/«аналог»/«расчёт», 5–10 главных наблюдений (где наш тарификатор сильно мимо рынка, ошибки ед. изм.) и список основных источников (URL).
