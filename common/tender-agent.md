name: "tender-agent"
description: "ИИ-агент/конвейер для тендеров — от документации к бюджету себестоимости и КП, с итерациями по замечаниям тендерного специалиста; read before work on agent design or this pipeline"
---

- Учится создавать ИИ-агентов; первый рабочий кейс — автоматизация тендерных КП
- Задуманный процесс: документация по тендеру → бюджет себестоимости → наценка 30% → КП по форме заказчика
- Итоговый выбор постановки: документация уже разложена по папкам (папка на тендер), результат кладётся в ту же папку
- Возражения/замечания тендерного специалиста должны отрабатываться на всех этапах, не только на финальном КП
- Изначальная задумка включала таблицу на Google Drive со ссылками на тендеры и отправку КП специалисту по почте
- Связано с [[kp-document-pipeline]] (существующая генерация КП в Node.js)
- Текущий процесс: мониторинг тендеров в Тендерплане → метка «первичный отбор» → интеграция создаёт сделку в воронке Битрикс24 (стадия «Первичный отбор») → документы по каждому лоту скачиваются в папку на рабочем столе, подключённую к Claude Code → анализ и расчёт через Claude Code
- Цель: чтобы агент сам ходил в Тендерплан, отбирал тендеры, ставил метки, работал с Битриксом, скачивал документы и выдавал результат
- Битрикс24 облачный (портал rps-official.bitrix24.ru)
- Работает с Claude Code через командную строку Windows; рабочая папка — Desktop\Сметы; доступы к API Тендерплана (токен) и вебхук Битрикс24 настроены и проверены
- Решение: агент ставит в Тендерплане только метку «Кандидат ИИ» (в Битрикс не синхронизируется); пользователь проверяет и сам ставит «Первичный отбор», дальше лот ведётся в Битриксе
